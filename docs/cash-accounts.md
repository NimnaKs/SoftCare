# Cash Accounts

## Overview
Cash accounts represent all monetary accounts owned by the organization, including:
- Bank accounts (Savings, Current, Fixed Deposit)
- Cash in hand (Cash, Petty Cash)
- Cheque in hand
- Cashier accounts (e.g., Cashier1, Cashier2)

Funds can be transacted through one or multiple methods:
- Cash
- Cheque
- Cards
- E-Transfers

## Account creation workflow
1. Select the account type.
2. Choose one or multiple transaction methods.
3. Enter account details.
4. Review the entered data before processing.
5. Proceed and confirm with a password prompt.

## Form fields
- Type (Bank, Cash in hand, Cheque in hand, Cashier)
- Transaction methods (multi-select)
- Account name
- Opening balance (+/-)
- Description

### Bank account details (required for Bank type)
- Bank account type (Savings, Current, Fixed Deposit)
- Account number
- Bank name
- Branch name
- Branch code
- Branch contact number
